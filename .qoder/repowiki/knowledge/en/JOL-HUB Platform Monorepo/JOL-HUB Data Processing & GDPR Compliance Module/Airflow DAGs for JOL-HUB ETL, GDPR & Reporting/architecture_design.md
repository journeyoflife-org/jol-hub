The module is an Apache Airflow project rooted at `data/airflow/` with four standard subdirectories: `config/airflow.cfg` pins the DAGs folder, plugins folder, PostgreSQL metadata DB (`postgresql://jolhub:jolhub@localhost:5432/jolhub_airflow`), and enables PII masking in logs; `dags/` contains one Python file per workflow — `jol_daily_sync.py` (daily ETL across 27 EU countries using a `TaskGroup` loop over country codes), `jol_hub_etl.py` (a main daily ETL plus a manual-only `jol_hub_gdpr_requests` DAG for Art. 15/17/20 data subject requests), `jol_gdpr_cleanup.py` (scheduled Article 17 retention cleanup), and `jol_weekly_reporting.py` (Monday analytics and compliance scorecard); `plugins/jol_operators.py` registers a custom `GDPRCompliantOperator` extending `PythonOperator` via the `AirflowPlugin` mechanism to enforce audit logging and PII masking around every task execution. Each DAG defines a shared `default_args` dict (owner, retries, retry_delay, email policy) and wires tasks with `DummyOperator` start/end markers and `>>` dependency chains, delegating all business logic to lazy-imported modules under `src.*` (e.g. `src.pipelines`, `src.gdpr`, `src.processors`, `src.quality.checkpoints`).
