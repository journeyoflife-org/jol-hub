Airflow must be configured with `dags_folder = /opt/jol/repos/jol-hub/data/airflow/dags` and `plugins_folder = /opt/jol/repos/jol-hub/data/airflow/plugins` in `airflow.cfg`; the plugin `JolHubPlugin` exposing `GDPRCompliantOperator` requires the Airflow instance to load plugins from that path. DAGs are scheduled via cron expressions (e.g. `0 2 * * *` for daily sync, `0 4 * * *` for GDPR cleanup, `0 3 * * 1` for weekly reporting) and the GDPR request DAG uses `schedule_interval=None` so it is triggered manually through the Airflow UI or API with a `dag_run.conf` payload containing `subject_id` and optional `requestor`.
