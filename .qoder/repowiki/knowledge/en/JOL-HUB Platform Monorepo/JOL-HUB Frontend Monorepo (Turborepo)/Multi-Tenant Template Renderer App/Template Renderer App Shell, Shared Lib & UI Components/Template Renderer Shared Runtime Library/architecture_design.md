This `lib/` directory is the orchestration layer between Next.js routes and the per-tenant content pipeline. `route-dispatch.tsx` is the central entry point for tenant-scoped routes: it resolves a tenant via `tenant-resolver`, loads seed fixtures (pilot fidelity), and delegates to either `renderFixtureRoute` or the STEP 6 composition system. `page-composer.tsx` then renders a validated `PageConfig`'s modules in JOL-controlled order, gating each by `isModuleEntitled` against tenant features and wrapping them in layout containers. The resolved tenant flows from server-side resolver → `TenantProvider` (`tenant-context.tsx`) as a stripped `PublicTenant` (schema removed) so only client-safe data crosses into React client components; feature flags are exposed via `useTenantFeature`. Cross-cutting concerns are centralized here: `content-loader`/`content-api` fetch fixtures and backend content, `editor-client`/`bitrix-client`/`auth` wrap external backends, `seo.tsx`/`json-ld.tsx` build metadata and schema.org entities, and `logger`/`error-tracking`/`rate-limit`/`slug` provide shared runtime services consumed by both server and client code paths.
