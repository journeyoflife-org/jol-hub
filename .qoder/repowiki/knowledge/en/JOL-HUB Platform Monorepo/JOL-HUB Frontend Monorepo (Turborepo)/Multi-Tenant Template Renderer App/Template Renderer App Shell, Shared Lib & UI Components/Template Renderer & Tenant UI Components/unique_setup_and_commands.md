Feature components are gated behind runtime checks (`isAuthConfigured()` for auth, `useTenantFeature` for commerce) so they render no-op in pilot/open modes without configuration. Telemetry components require the `analytics` flag in `localStorage` key `jol-cookie-consent` before sending metrics to `/api/perf` or `/api/telemetry/perf`. Commerce cart state is persisted under `jol.cart.v1.<tenantSlug>` in `localStorage` and must be wrapped in `<CartProvider>` to access `useCart`.
