The module implements a layered rendering pipeline for Next.js server components:
- Data layer (`content-api.ts`, `content-loader.ts`): `content-api.ts` is the sole outbound HTTP client to the backend content service over `BACKEND_API_URL`, attaching RLS headers (`x-tenant-schema`, `x-tenant-id`, optional Bearer token) and returning typed `TenantPage`, `ContentBlock`, or collection items via Zod validation; it maps 403/404/5xx to a `ContentApiError` taxonomy and deduplicates concurrent requests with an in-flight map. `content-loader.ts` provides fixture-only lookups from `@jol-hub/seed-data` for pilot tenants.
- Route dispatch (`route-dispatch.tsx`): central entry point enforcing two invariants — unknown tenants call Next's `notFound()` (no enumeration) and fixture-first fidelity returns a `TemplateRenderer` when a seed page exists, otherwise falling through to composition.
- Config layer (`page-config.ts`, `page-defaults.ts`): defines the module vocabulary (`ModuleTypeSchema`, `ModuleLayoutSchema`) and validates every incoming config via `parsePageConfig`, emitting a sanitized fallback `buildFallbackConfig` on parse failure; `page-defaults.ts` supplies JOL-controlled default compositions (home/about/contact).
- Composition (`page-composer.tsx`): async React Server Component that iterates validated `PageConfig.modules`, filters by tenant entitlement (`isModuleEntitled`) and visibility, renders each via the module registry, and wraps them in layout containers (`full-width`, `contained`, `two-column-*`, `three-column`).
- Collections (`collections.ts`, `collection-view.ts`): Zod schemas for news/events/services items plus generic `getCollection`/`getCollectionItem` helpers that wrap `content-api` calls, paginate, split events by time, and build calendar grids; `collection-view.ts` exposes pure SSR helpers for search params, pagination URLs, and localized weekday/month labels.
- Template resolution (`template-registry.ts`): lazy-loads vertical-specific template components keyed by `tenant.vertical` (with optional VIP-gated `settings.templateOverride`) and maps the STEP-5 vertical taxonomy to design-system accent tokens.
Dependency direction is strictly one-way: route-dispatch → content-loader/content-api → collections/page-config → page-composer → template-registry, with no cross-imports between leaf concerns.
