The `index.ts` barrel re-exports six sibling modules so consumers import from `@/lib/editor` rather than individual files. The architecture splits concerns by file: `blocks.ts` defines the immutable block data model; `diff.ts` computes revision-aware diffs over that model; `sanitize.ts` enforces escape-first rendering with URL allowlisting; `moderation.ts` provides domain types and queues for content safety; `validation.ts` applies Zod schemas to draft blocks before they reach the backend; and `editor-api.ts` is the typed HTTP client that serializes validated blocks to the server. React components in `@/components/editor` consume this barrel exclusively, keeping UI separate from the pure primitives documented in the barrel header.
