Root commands: `pnpm build` runs Turborepo build across the workspace; `pnpm build:all` builds all apps; `pnpm build:infrastructure` builds admin-dashboard, master-site, parish-template; `pnpm build:entities` builds template-renderer; `pnpm build:packages` builds all shared packages; `pnpm dev` starts all apps in parallel via Turbo; `pnpm test` runs unit tests across packages and apps; `pnpm release` builds packages then publishes via Changesets.
