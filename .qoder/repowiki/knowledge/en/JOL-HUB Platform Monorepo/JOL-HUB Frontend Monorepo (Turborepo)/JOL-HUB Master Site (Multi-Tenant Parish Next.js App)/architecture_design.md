Built on Next.js App Router with a multi-tenant architecture driven by middleware. `src/middleware.ts` is the entry point: it extracts the subdomain from the request host, rejects invalid/reserved ones, rewrites parish subdomain requests into the dynamic `[parish]` route, and attaches security + parish context headers (`x-parish-subdomain`, `x-parish-id`, CORS). The root `src/app/layout.tsx` sets global fonts (Inter, Merriweather), metadata, and viewport for the master site. Per-parish rendering lives in `src/app/[parish]/layout.tsx` and `page.tsx`, which resolve parish config via `@/lib/tenant/resolver`, generate per-parish metadata and CSS custom properties, wrap children in `ParishProvider`, and declare ISR revalidation of 3600s plus `generateStaticParams` for a fixed set of mock parishes. `src/components/tenant/ParishProvider.tsx` exposes a React Context (`useParish`, `useParishSafe`, `useIsInParish`) plus storage-key and API-header helpers that prefix localStorage keys with `parish:<id>:` and inject parish headers into client fetches, ensuring data isolation between tenants. Authentication is wired through NextAuth at `src/app/api/auth/[...nextauth]/route.ts`. UI primitives are split into local shims under `src/components/*.tsx` (Radix-based) and shared design tokens via the workspace package `@jol-hub/ui`. Tenant resolution and configuration live in `src/lib/tenant/` (resolver, config, utils), keeping business logic out of components. Image domains are whitelisted to `localhost` and `cdn.jol-hub.eu` in `next.config.js`, and i18n is configured for `lt`, `ru`, `en` with Lithuanian as default.
