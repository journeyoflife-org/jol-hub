Run with `pnpm dev` (Next dev on port 3000); build via `next build`; type-check via `tsc --noEmit`. Requires `NEXTAUTH_SECRET` env var for NextAuth. Local development supports simulating parish subdomains via an `x-subdomain` header when hitting `localhost`. Preview deployments handle hosts containing `--` (e.g. Vercel preview URLs) by treating the first segment as the parish subdomain.
