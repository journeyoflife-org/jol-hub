Dev server runs on port 3002 (`pnpm dev`). Pre-commit runs `compliance:check && lint && type-check`; pre-push runs `build`; pre-deploy invokes `scripts/pre-deploy-check.sh` which validates TypeScript, ESLint, production build, `.env.local` presence, critical env vars (`NEXTAUTH_SECRET`, `NEXTAUTH_URL`, `NEXT_PUBLIC_API_URL`, `BITRIX24_WEBHOOK_SECRET`, `ENCRYPTION_KEY`), scans for hardcoded secrets, verifies GDPR/CountryGuard usage, canonical workflow components, Bitrix24 webhook signature verification, feature flags, and dependency audit. Compliance scripts `scripts/compliance-audit.js` and `scripts/gdpr-schema-check.js` are invoked via `pnpm compliance:full`.
