Single-package library (`@jol-hub/a11y`) built with tsup into ESM + CJS under `dist/`, re-exporting from `src/index.ts`. The runtime entry point is `test-utils.ts`, which boots a jsdom document, injects `axe-core` source, runs the WCAG 2.0–2.2 AA tag set defined in `axe-config.ts`, and merges results with structural checkers in `src/checkers/` (heading-hierarchy, alt-text, focus-order, form-labels, aria-usage, color-contrast). All checkers conform to the shared `A11yFinding` / `A11yReport` types in `types.ts`, so consumers get one uniform report shape regardless of whether a finding came from axe or a custom checker. The `axe-config.ts` module is the single source of truth for rule selection and jsdom-specific overrides (e.g. disabling `color-contrast` because jsdom has no layout engine); a `browserHarness` flag lets Playwright-based E2E tests re-enable those rules. Consumers include the ui showcase gate, the template-renderer page gate (`scripts/check-a11y-pages.ts`), and a future Playwright harness.
