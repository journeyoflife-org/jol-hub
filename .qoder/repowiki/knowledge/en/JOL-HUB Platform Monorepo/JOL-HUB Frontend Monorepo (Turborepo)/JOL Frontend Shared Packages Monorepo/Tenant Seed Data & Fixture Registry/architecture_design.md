The package is a small npm library (`@jol-hub/seed-data`) built with tsup that re-exports two modules: `schema.ts` (Zod schemas defining the fixture contract) and `registry.ts` (the runtime fixture store). All JSON files under `src/fixtures/tenants/` are statically imported into `registry.ts`, collected into a single array, and parsed at module load time via `TenantFixtureSchema.parse`; any malformed fixture fails build/deploy rather than producing invalid data. The parsed fixtures are exposed as a readonly `tenantFixtures` array and a `tenantRegistry` Map keyed by slug, plus lookup helpers (`isKnownTenant`, `getTenantFixture`, `getTenantFixtureWithFallback`) and a `DEFAULT_TENANT_SLUG`. Schemas in `schema.ts` define a discriminated union of content blocks (`hero`, `text`, `keyValue`, `schedule`, `list`, `stats`, `cta`, `massSchedule`, `gallery`, `faq`, `sacramentList`, `clergyRoleList`, `visitingInfo`, `mapLocation`) composed into pages and tenants, enforcing locale parity (`lt` required, `en`/`ru` optional), image dimensions for CLS, and GDPR constraints (no clergy names in fixtures — only roles). The package has no runtime dependencies beyond zod and publishes only its `dist/` folder to GitHub's npm registry.
