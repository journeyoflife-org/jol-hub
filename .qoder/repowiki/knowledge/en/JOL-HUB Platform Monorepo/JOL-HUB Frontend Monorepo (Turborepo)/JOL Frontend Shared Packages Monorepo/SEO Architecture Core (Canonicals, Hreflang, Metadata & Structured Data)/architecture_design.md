Single TypeScript package (`@jol-hub/seo`) built by tsup into ESM + CJS with d.ts under `dist/`, re-exported from `src/index.ts`. The module is intentionally framework-agnostic — it contains no Next.js or DOM dependencies and is consumed by the renderer in `apps/template-renderer/lib/seo.tsx` which composes these pure builders into Next.js Metadata/JSON-LD. Internal layering follows a one-concern-per-file layout: `types.ts` defines shared domain types (`SeoPageKind`, `HreflangLocale`, `SitemapEntryInput`, `IndexNowPayload`, `Json`); `canonical.ts` enforces absolute canonical URLs with query/fragment/trailing-slash stripping; `hreflang.ts` builds complete reciprocal alternate sets using the canonical builder; `metadata.ts` clamps descriptions to 150–160 chars and drives index/follow policy by page kind; `structured-data.ts` emits schema.org JSON-LD for LocalBusiness/Product/FAQ/WebSite and church entities; `sitemap.ts` provides per-kind changefreq/priority policy and 50k-URL sharding; `robots.ts` centralizes disallow/allow lists; `open-graph.ts` defines image dimensions and fallback resolution; `indexing.ts` builds IndexNow payloads. Dependency direction is strictly inward toward `types.ts` and `canonical.ts`; no file imports another except `hreflang.ts` → `canonical.ts` and all structured-data files → `types.ts`.
