Single-package npm module (`@jol-hub/perf`) built with tsup into ESM + CJS dual outputs under `dist/`, re-exported via `src/index.ts`. Internal layering is flat by concern: `types.ts` defines the shared domain model (`LighthouseBudget`, `RouteFootprint`, `BudgetGateResult`); `budget.ts` parses and validates a Lighthouse-format budget JSON defensively (whitelisting allowed resource types and timing metrics); `measure.ts` computes gzipped first-load footprints from a Next.js `.next/app-build-manifest.json` using an injected `AssetReader` interface so the core stays pure and testable; `report.ts` evaluates footprints against KiB budgets, subtracts legacy `noModule` polyfill chunks, and formats a human-readable CI log. Dependency direction is strictly one-way: `report.ts` → `measure.ts` → `types.ts`; `budget.ts` depends only on `types.ts`. The package has no runtime dependencies — it uses only Node built-ins (`node:zlib`, filesystem via injection) so it can run offline in CI without network access.
