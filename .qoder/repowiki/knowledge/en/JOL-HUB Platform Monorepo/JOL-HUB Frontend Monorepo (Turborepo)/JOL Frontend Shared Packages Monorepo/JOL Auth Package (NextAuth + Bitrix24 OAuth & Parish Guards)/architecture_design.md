The package is built with tsup into dual ESM/CJS bundles under `dist/`, exposing multiple subpaths (`@jol-hub/auth`, `@jol-hub/auth/middleware`, `@jol-hub/auth/hooks`, `@jol-hub/auth/api`, `@jol-hub/auth/oidc`, `@jol-hub/auth/oidc/hooks`) via `package.json` exports. The root barrel (`src/index.ts`) re-exports configuration, the Bitrix24 provider, session helpers, hooks, middleware, API client, and shared types. Internal layering: `providers/bitrix24.ts` implements a NextAuth OAuth2 provider with PKCE (S256) and token refresh; `auth-options.ts` wires it into NextAuth; `session.tsx` wraps `next-auth/react` in a React context (`SessionProvider`, `useSession`) plus server-side placeholder functions; `middleware/parish-guard.ts` provides a factory `createParishGuardMiddleware` that enforces public/auth-only/admin paths and per-parish subdomain access by extracting user info from request headers/cookies and emitting audit logs; `lib/bitrix-api.ts` exposes a typed Bitrix REST client; `hooks/useBitrixAuth.ts` composes session state and parish guards into React hooks; `oidc/` is split into a server-safe barrel (`index.ts` exporting types, RBAC, config, options) and a separate `hooks.ts` entry to avoid importing React on the server. Dependencies flow inward: hooks → session → providers/types; middleware depends only on Next.js runtime and shared types; oidc is isolated from React entirely.
