Consumers must register `@jol-hub/testing/setup` in their vitest config's `test.setupFiles` to activate the global cleanup, timezone, and jsdom shims. Build the package with `pnpm build` (tsup) which emits both ESM and CJS under `dist/`; type-check via `tsc --noEmit`. Tests are expected to run against `BACKEND_API_URL=http://backend.test` so MSW handlers intercept all backend calls.
