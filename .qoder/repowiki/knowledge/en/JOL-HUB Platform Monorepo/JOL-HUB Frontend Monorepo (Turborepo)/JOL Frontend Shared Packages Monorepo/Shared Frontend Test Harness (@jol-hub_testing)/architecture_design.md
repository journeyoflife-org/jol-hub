The package is built with tsup into dual ESM/CJS bundles under `dist/`, exposing two entry points via `package.json` exports: `.` (render helpers + mocks + fixtures) and `./setup` (vitest global setup). Internal layering follows a clear dependency direction:
- `src/setup.ts` — vitest `setupFiles` hook that enforces determinism (UTC timezone), auto-cleans RTL DOM after each test, restores mocks, and shims missing jsdom globals (`matchMedia`, `scrollTo`, `IS_REACT_ACT_ENVIRONMENT`).
- `src/render.tsx` — `renderWithProviders` wraps components in the same provider stack as production apps (`ThemeProvider` from `@jol-hub/ui` → `TranslationProvider` from `@jol-hub/i18n`), with an optional app-level `wrapper` composed outside i18n so the package stays decoupled from app-specific providers.
- `src/mocks/` — three mock modules: `tenant.ts` returns deterministic `Tenant` objects per package tier; `auth.ts` defines a local `MockAuthSession` interface (mirroring `@jol-hub/auth/oidc`) and factory functions for admin/superadmin/viewer sessions with a fixed future expiry; `api.ts` ships MSW handlers against `MOCK_BACKEND_URL = 'http://backend.test'` covering editor draft/publish, moderation queue, media library, and perf endpoints, plus canned `MOCK_DRAFT`, `MOCK_MODERATION_QUEUE`, `MOCK_MEDIA_LIBRARY` payloads.
- `src/fixtures/blocks.ts` — plain-object fixtures (`FixtureBlock[]`) including valid drafts and a canonical XSS payload battery (`XSS_PAYLOADS`, `CONTACT_XSS_PAYLOADS`) reused across sanitization tests.

The package has runtime dependencies on `react`, `react-dom`, `@jol-hub/i18n`, `@jol-hub/tenant-resolver`, and `@jol-hub/ui`, but declares `@testing-library/react` and `vitest` as peer dependencies so consuming apps supply their own versions. It is consumed by other workspace packages via workspace protocol (`workspace:*`) and published to GitHub Packages under `@jol-hub/testing`.
