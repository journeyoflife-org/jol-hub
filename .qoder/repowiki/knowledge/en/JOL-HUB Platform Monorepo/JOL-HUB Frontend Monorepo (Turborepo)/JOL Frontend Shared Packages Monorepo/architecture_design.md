Each subdirectory under `frontend/packages/` is an independently published npm package (e.g. `@jol-hub/auth`, `@jol-hub/commerce`, `@jol-hub/ui`) built with tsup and orchestrated by the root Turborepo (`turbo.json`). Cross-package wiring is purely via npm dependency edges — packages declare peer or regular dependencies on one another (for example, `auth` depends on `tenant-resolver` and `observability`; `ui` consumes `a11y` and `seo`; `testing` re-exports mocks for all others) — and there is no runtime orchestrator: each package exposes a stable public API surface that consuming apps in `frontend/apps/*` compose at startup. The monorepo enforces a uniform build/test/lint pipeline through Turbo tasks (`build`, `type-check`, `test`, `lint`) and a top-level `pnpm test:unit` script that runs every package's tests in sequence, while `changesets` drives versioning and publishing across the package set.
