The package is a dual-runtime library built with tsup and published as `@jol-hub/i18n` with explicit subpath exports (`./`, `./client`, `./server`, `./middleware`, `./provider`, `./use-translations`, `./use-locale`, `./messages`, `./config`, `./types`, `./utils`). It separates concerns into layered modules:
- Pure configuration (`src/config.ts`, `src/types.ts`) defines supported locales (lt/en/ru), URL prefixes, cookie names, fallback order, and path helpers — no React or i18next imports so it runs in edge/server components.
- Message pipeline (`src/messages/index.ts`) loads per-locale JSON catalogs plus tenant-vertical overrides (church/funeral/cleaning), merges them via a cached `deepMerge` with last-wins semantics, and exposes server-safe `translate` / `translateWithValues` using `intl-messageformat` for ICU interpolation.
- Legacy runtime (`src/i18next.ts`) initializes i18next + react-i18next with browser language detection and static resources; kept separate to keep the main barrel free of client-only code.
- Client boundary (`src/components/translation-provider.tsx`, `src/hooks/use-translations.ts`, `src/hooks/use-locale*.ts`, `src/client.ts`) provides a React context carrying `{locale, direction, messages}` and a memoized `useTranslations(namespace)` hook that caches `IntlMessageFormat` instances per key.
- Middleware (`src/middleware/language.ts`) implements Next.js Edge middleware with priority: URL path → cookie → Accept-Language → default lt, issuing 301 redirects and setting `x-locale` headers.
- Liturgical guard (`src/lib/liturgical.ts`) contains regex-based detection of sacred text and a clergy-verified term dictionary (`LITURGICAL_TERMS`) that bypasses machine translation.
- DeepL integration (`src/lib/deepl-client.ts`, `src/lib/deepl-server.ts`) offers client-side and server-side translation functions gated by the liturgical guard.
Dependency direction flows inward: components/hooks depend on messages/config; middleware depends only on config/types; nothing in the pure layer depends on React or i18next. The package's `package.json` peerDependencies pin Next ≥14 and React 18, and scripts under `scripts/` enforce translation parity and detect hardcoded strings.
