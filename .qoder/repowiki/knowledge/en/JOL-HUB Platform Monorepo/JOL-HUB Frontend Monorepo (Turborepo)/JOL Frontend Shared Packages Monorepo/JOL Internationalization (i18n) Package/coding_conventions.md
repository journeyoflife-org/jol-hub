- Client-only code (React hooks, components, i18next initialization) is isolated behind dedicated subpath exports (`./client`, `./provider`, `./use-translations`, `./use-locale`) so the main barrel remains importable from Server Components without triggering RSC bundle evaluation failures.
- Locale constants are centralized in `src/types.ts` and re-exported through `src/config.ts`, which stays a pure module with no React/i18next imports to remain safe in edge/runtime contexts.
- Message lookups use dot-separated keys resolved against a merged catalog, with missing keys falling back to the raw key path so they are visibly caught by CI parity checks.
- ICU interpolation is performed lazily via `IntlMessageFormat` instances cached per key inside `useTranslations`, with a fast path that returns the pattern unchanged when no values or ICU syntax are present.
- Vertical tenant overrides are mapped via a switch function (`mapTenantVertical`) that groups seed-data verticals (cemetery/funeral-home → funeral, parish/basilica/chapel → church, cleaning-service → cleaning) before merging into the base catalog.
- Liturgical content is protected by a two-layer guard: regex-based `containsLiturgicalContent` blocks any text matching Bible references or named prayers from being sent to DeepL, and `LITURGICAL_TERMS` provides clergy-verified canonical translations for known terms.
