The package is a multi-entry npm library built with tsup, emitting ESM/CJS plus `.d.ts` files under `dist/`. The public surface is split across subpath exports declared in `package.json`: the root barrel (`.`) re-exports legacy flat components (accordion, dialog, toast, etc.) alongside parish templates (LiturgicalCalendar, ContactForm, PhotoGallery, ServiceSchedule), GDPR pages (PrivacyPage, ConsentPage, DSRPage), cookie consent, PII encryption helpers, and an Entity CRM hook; dedicated subpaths expose the new STEP 3 surfaces — `components/primitives`, `components/composite`, `components/layout`, `components/accessibility`, `components/locale-switcher`, plus `tokens`, `providers`, and `dev/showcase`. Each component lives in its own folder with a `<Name>.tsx`, `<Name>.types.ts`, and `index.ts` barrel. Primitives are thin wrappers around `@radix-ui/*` primitives styled with Tailwind via the shared `cn()` utility (`clsx` + `tailwind-merge`). Theme tokens live under `src/tokens/` (colors, spacing, typography, radii, shadows, breakpoints, themes) and are compiled to CSS via `scripts/generate-css.ts`. Accessibility primitives (`SkipLink`, `FocusTrap`, `AnnouncerProvider`/`useAnnounce`, `LiveRegion`) form a reusable foundation for dialogs and focus management. Consumers depend on peer versions of React/Next, while `@jol-hub/i18n` is a workspace dependency used by i18n-driven composites.
