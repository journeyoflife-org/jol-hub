Single npm package (`@jol-hub/observability`) built by tsup into ESM/CJS + d.ts under `dist/`, exposing a flat barrel in `src/index.ts`. Internally split into five independent modules with one-way dependencies: `redact.ts` is the leaf utility used by every other module; `logger.ts` composes `redact` to produce JSON-lines records via pluggable `LogSink`s and adds a client-side batching sink; `error-tracking.ts` classifies errors into categories/severities, computes stable fingerprints, and manages bounded breadcrumb buffers; `performance.ts` derives navigation phase timings and resource summaries plus a generic metric batcher; `health.ts` aggregates dependency probes into an overall report with timeout/race helpers. All modules are pure logic with no React/Next/node:* imports so they run on server, browser, and edge; bindings that touch platform APIs live in the template renderer and routes outside this package.
