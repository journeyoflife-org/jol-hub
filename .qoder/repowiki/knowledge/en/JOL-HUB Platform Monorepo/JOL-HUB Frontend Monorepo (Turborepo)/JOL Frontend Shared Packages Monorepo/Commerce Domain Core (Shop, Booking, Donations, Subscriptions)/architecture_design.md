Single-package library (`@jol-hub/commerce`) built with tsup to ESM + CJS plus `.d.ts` declarations under `dist/`, re-exported from `src/index.ts`. Internal layering is flat by concern: `types.ts` defines the shared domain vocabulary (Product, Cart, Order, BookingSlot, SubscriptionPlan, DonationRequest) with all monetary values as integer `Cents`; `money.ts` provides pure VAT/EUR formatting functions using `Intl.NumberFormat` and the LT 21% rate; `cart.ts` exposes an immutable function API over `Cart` (add/remove/setQuantity/subtotal); `gating.ts` maps `CommerceCapability` feature names to feature flags consumed by `@jol-hub/tenant-resolver`'s `FEATURES_BY_TIER`; `commerce-api.ts` is the only side-effectful module — it wraps `fetch` calls to the `jol-ecommerce-engine` backend, injects `X-Tenant` headers for RLS, classifies errors into `CommerceErrorKind`, retries idempotent GETs with exponential backoff, and returns a discriminated union `CommerceResult<T>` so callers handle success/failure without exceptions. The package has no runtime dependencies and deliberately excludes React — UI bindings live in the template renderer.
