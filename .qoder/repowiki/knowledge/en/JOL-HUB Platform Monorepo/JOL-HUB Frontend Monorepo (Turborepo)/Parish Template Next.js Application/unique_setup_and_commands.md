The app runs on port 3001 (`npm run dev` / `npm start`). It requires a `NEXT_PUBLIC_DJANGO_API_URL` environment variable to connect to the obituary backend; without it, the funeral template falls back to mock data. Production cookie scoping is gated on `NODE_ENV=production` (sets domain `.jol-hub.eu` and `secure: true`). Clean artifacts with `npm run clean` which removes `.next`, `.turbo`, and `node_modules`.
