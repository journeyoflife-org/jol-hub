Each top-level ISO country code directory (`ee`, `lt`, `lv`) is a self-contained configuration bundle with a uniform layout: a `config/` folder holding YAML policy files (`compliance.yml`, `liturgical.yml`, plus `seo.yml` or `bitrix24.yml` where applicable) that declare country-scoped rules such as GDPR lawful basis, retention periods, DPA contacts, dioceses, basilicas, and local feast days; an `examples/` folder mirroring canonical church hierarchy (catholic/orthodox/protestant branches with subfolders like `diocese`, `cathedral`, `parish`, `deanery`) each containing an `entity.yml` describing a concrete jurisdictional entity with canonical metadata, contact info, domain, features, and Bitrix24 integration flags; and optional `templates/` directories for site templates per entity type. A separate `test-parish-lt-5/parish.json` in the Lithuania tree provides a JSON fixture for test parish provisioning. There is no executable code here — this module is pure declarative configuration consumed by higher layers to bootstrap country-specific behavior.
