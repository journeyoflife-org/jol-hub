Terraform state backend is commented out by default in `main.tf` and must be uncommented and configured (S3 bucket + DynamoDB lock table) before production runs; `terraform.tfvars.example` provides variable templates. Kustomize builds are driven from `infra/kubernetes/kustomization.yaml` which applies image tag overrides and replica patches. Helm chart defaults live in `infra/helm/jol-hub/values.yaml` and are intended to be overridden per environment via `-f values.<env>.yaml`.
