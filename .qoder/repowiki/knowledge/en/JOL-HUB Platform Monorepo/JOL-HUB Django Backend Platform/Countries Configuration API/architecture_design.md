A self-contained Django app (`apps.countries`) following standard DRF conventions: `models.py` defines a single `Country` model (extending `apps.core.models.BaseModel`) storing ISO code, name, currency, GDPR consent age, VAT rate, supervisory authority info, plus JSON fields for `supported_payment_methods` and `feature_flags`; data is seeded via `migrations/0001_initial.py` and rarely mutated at runtime. `views.py` exposes two DRF generic views — `CountryListView` (list) and `CountryDetailView` (retrieve by ISO `code`) — both restricted to authenticated users and filtering on `is_active=True`. `serializers.py` uses a read-only `BaseModelSerializer` subclass that serializes all fields as read-only. `urls.py` mounts the app under `app_name='countries'` with routes `''` and `<str:code>/`, intended to be included under `/api/v1/countries/`. The app depends only on `apps.core` for shared base model/serializer and has no internal sub-packages.
