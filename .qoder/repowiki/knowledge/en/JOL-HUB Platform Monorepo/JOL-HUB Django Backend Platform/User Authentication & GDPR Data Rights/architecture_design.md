The app is a standard Django reusable app (`apps.users`) organized by Django REST framework conventions. `models.py` defines a custom `User` extending `AbstractBaseUser` + `PermissionsMixin` with email as `USERNAME_FIELD`, plus a one-to-one `UserProfile` for extended fields; both inherit shared base classes from `apps.core.models`. A custom `UserManager` in `managers.py` enforces email-only creation and exposes an `active()` queryset that filters out deleted users. `views.py` groups endpoints into three logical areas: auth (register/login/logout/refresh via `rest_framework_simplejwt`), profile (self `MeView`, password change, admin list/detail), and GDPR (access/export/delete under `/me/gdpr/`). Serializers in `serializers.py` mirror these concerns, reusing `BaseModelSerializer` from `apps.core.serializers`. URL routing is split across two namespaces — `auth_urls.py` for `/api/v1/auth/*` and `urls.py` for `/api/v1/users/*` — mounted by the root project. Cross-cutting behavior is handled by `signals.py`: a `post_save` signal auto-creates a `UserProfile` on user creation, and a `user_logged_in` signal updates last-login IP and login count. The `AppsConfig.ready()` method imports signals to ensure registration at startup. Sensitive endpoints are protected with DRF throttles from `apps.core.throttling` and integrate with an external DSAR pipeline via `apps.core.data_integration.get_data_integration()`, which is lazily imported inside view methods to avoid circular imports.
