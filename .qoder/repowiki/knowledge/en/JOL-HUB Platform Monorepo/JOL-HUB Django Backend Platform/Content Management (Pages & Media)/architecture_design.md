Standard Django REST Framework app organized by concern: `models.py` defines `Page` and `MediaFile` both extending `apps.core.models.BaseModel`, each scoped to an `Organization` via ForeignKey and enforcing tenant isolation through a `_validate_tenant_context()` hook in `save()` that calls `apps.crm.middleware.get_current_tenant_id()` to reject cross-tenant mutations. `serializers.py` exposes read/write contracts via `BaseModelSerializer` subclasses (`PageSerializer`, `PageCreateSerializer`, `MediaFileSerializer`) with nested `featured_image` serialization. `views.py` implements DRF generic views (`ListCreateAPIView`, `RetrieveUpdateDestroyAPIView`, `RetrieveDestroyAPIView`) plus a custom `PagePublishView` for the publish action; all endpoints require `IsAuthenticated` and filter by `is_deleted=False`. `urls.py` mounts the routes under `pages/` and `media/` with `app_name = 'content'`. `admin.py` registers both models with list filters, search, and raw ID fields. Cross-app dependencies are one-way: this app depends on `apps.core`, `apps.organizations`, and optionally `apps.crm.middleware` at runtime.
