`backend/manage.py` is a shim that `chdir`s into `backend/django/` and execs the real `manage.py` so `sys.path` and import roots match the container; never add `backend/` to `sys.path` or the local `django/` package will shadow the framework. Celery runs via `celery -A core worker` / `celery -A core beat` with `DJANGO_SETTINGS_MODULE=core.settings.development` set in `celery.py`. Environment variables are loaded from `backend/django/.env` via `environ.Env.read_env(BASE_DIR / '.env')`.
