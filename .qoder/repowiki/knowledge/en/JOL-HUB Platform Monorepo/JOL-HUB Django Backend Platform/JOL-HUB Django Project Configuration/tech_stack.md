Django 4.2 with Django REST Framework, SimpleJWT (HS256), django-allauth (Google/Facebook providers), drf-spectacular for OpenAPI, django-cors-headers, WhiteNoise, django-redis + Redis broker/backend for Celery and caching, django-celery-beat, django-filters, python-environ + python-dotenv for `.env` loading, PostgreSQL as primary DB and MongoDB as secondary document store, Prometheus metrics endpoints gated by IP/token.
